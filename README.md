# Project Turner Angle

The problem isn't just different names, but that I am a new person everywhere you meet me! I won't be deleting any of my old stuff on my other accounts, but I will be rebranding them. 

I'm calling this project the Turner Angle.
1. It connects my real name with my my aliases, which is the point of this project.
2. Turner Angle is an actual thing, which I find funny.
